# U 校园 / UnipusAI 3.6 使用说明

适用于本整合包中的 `UnipusAI-v3.6-windows-x86-64`。工具来源：[Zzj-klwgxdz/UnipusAI](https://github.com/Zzj-klwgxdz/UnipusAI/tree/3.6)。启动器负责启动与配置管理，具体平台能力由第三方工具提供。

## 首次配置与启动

1. 完整解压 `full` 整合包，不要直接在压缩包内运行 EXE。
2. 打开 `TimeSaver.exe`，选择 UnipusAI，在“设置”页填写并保存所需配置；也可以直接启动工具，按其登录提示完成登录。
3. 在 U 校园网页确认同一账号可以打开目标课程和单元。首次登录、课程选择等需要用户自己完成。
4. 在 UnipusAI 中按 `c` 选择课程，核对当前课程，再导入课程内容。AI 供应商相关设置以该版本实际提供的字段为准；请勿公开包含账号、Cookie、令牌或 API Key 的 `config.json`。

## 缺少单元：一键补抓

先退出正在运行的 UnipusAI，避免多个实例同时访问数据库。启动器关闭窗口可能只是隐藏到托盘；请确认工具进程已正常退出。

将补充包解压到整合包根目录并合并同名文件夹，最终结构如下：

```text
整合包根目录/
  TimeSaver.exe
  UnipusAI-v3.6-windows-x86-64/
    UnipusAI.exe
    config.json
    Import-Missing-Units.cmd
    U校园使用说明.md
```

双击 `Import-Missing-Units.cmd`，等待结束，查看窗口底部的汇总与 `Exit code`。下载单独 CMD 的用户，也可把它放在整合包根目录；它会查找同级的上述 UnipusAI 文件夹。脚本不要求固定盘符或用户名，路径含空格也可使用。

脚本执行 `UnipusAI.exe dump-text`，读取当前已保存的账号和课程配置，进行增量内容导入。它不会加入 `--force`、清空数据库、修改配置或执行答题与课程提交。已有有效内容通常跳过，缺失内容重新获取；若启用了媒体转写，导入期间仍可能下载媒体或本地模型。导入会更新本地数据库，运行前可自行备份工具目录。

`Exit code: 0` 表示命令正常结束，仍应核对汇总和单元列表；非零表示失败，请保留错误文字。补抓后重新打开工具查看列表，或在工具内按 `r` 重载本地缓存。也可以在工具内按 `d`，然后按 Enter 发起增量导入。`r` 本身不会从平台补抓数据。

不要把大写 `F` 当作普通刷新：该版本的强制导入路径会先清空本地账号数据库，使用前务必备份。

## 常见问题

### 缺失必修单元

必修策略控制执行时的筛选，不决定 `dump-text` 导入哪些单元。仅把策略改成“全部”不能修复导入缺失。先确认网页能打开这些单元，再运行增量补抓；接口失败可能导致后续单元未能导入。

### HTTP 403 Forbidden / 没有权限

HTTP 403 表示当前请求被服务端拒绝；HTTP 200 响应中的“没有权限”是另一种业务错误，不能只看 HTTP 状态判断成功。先核对网页能否正常访问、当前登录状态与所选课程，并查看完整错误文字。不要随意替换 `course_id`、`open_id` 或版本号；网页上看见的公共教材 ID 与账号关联课程 ID 可能不同。

补抓脚本不修复服务端权限、登录兼容或网络问题。网页正常而工具仍失败时，应向上游反馈脱敏错误与版本；不要分享完整请求头、Cookie、令牌、配置文件或整个个人数据库。遇到 403 不要反复连续重试。

### 操作过于频繁 / 请求限流

限流规则由 U 校园服务端决定，网页没有可供脚本修改的限流阈值。`config.json` 中的 `interval_ms` 默认 `3000`，用于执行任务循环的间隔；它不是所有 HTTP 请求的统一节流器，也不能据此保证 `dump-text` 补抓不会触发限流。该版本任务提交路径还内置了重试与冷却逻辑。

如需修改执行间隔，先退出工具、备份配置，再调整已有 `interval_ms` 的数值，保持 JSON 格式正确。出现限流应停止连续重试并等待。AI 供应商返回的 429 属于模型接口限流，需要另行查看供应商额度和频率限制。

### TUN / 代理

开启 FlClash TUN 不等于存在某个固定本地 HTTP 代理端口。显式代理地址应使用 FlClash 实际显示的 HTTP/Mixed 监听地址和端口；不要凭空填入端口。具体代理支持以 UnipusAI 版本为准。本补充包不修改网络、证书或代理设置，也不保证所有 TUN 模式组合可用。

## 补充包范围与验证

补充包仅包含本说明和一键补抓 CMD，不包含账号、密钥、数据库或新的 UnipusAI 二进制。它沿用整合包内的 3.6 版本。发布前使用模拟 EXE 验证目录查找、包含空格与单引号的路径、参数及退出码传递；真实账号的导入结果仍需在用户本机核对。
